## פיצ'רים שהושלמו ללא תכנון מוקדם (Implemented — not originally planned)

פיצ'רים שנוספו לפרויקט אך לא היו ברשימת התכנון המקורית. רשומים כאן לצורך תיעוד:

- [x] **Auto Booster Loop** — לולאה אוטומטית של משחק ↔ מחזק ללא מסך "כל הכבוד" באמצע.
- [x] **3 מצבי תצוגת מילה** — `letters` / `word` / `hidden` (הרחבה מעבר לפיצ'ר המקורי של "אותיות קטנות בכרטיס אחד").
- [x] **Hint Cooldown** — זמן צינון בין רמזים עם חיווי ויזואלי של טיימר.
- [x] **Virtual Keyboard Modes** — `none` / `full` / `focused` (מצב ממוקד שמראה רק אותיות רלוונטיות למילה הנוכחית).
- [x] **Card Repetitions** — שליטה במספר חזרות על כל כרטיס בסבב.
- [x] **תצוגה מקדימה למחזק ממסך ההגדרות** — כפתור "הצגת דוגמה" לבדיקת הבוסטר לפני משחק.
- [x] **Preload Assets** — טעינה מוקדמת של כל התמונות והסאונד בעת פתיחת המשחק למניעת איטיות.
- [x] **Cloud Assets (Cloudflare R2)** — מעבר כל הנכסים לאחסון בענן עם סנכרון חכם (MD5).
