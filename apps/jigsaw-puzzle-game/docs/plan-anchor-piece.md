## חלק 1: פאזל ממורכז (מצב מסודר)

### מצב נוכחי
כש-`shufflePiecePlacement=false` (מצב מסודר), הפאזל ממוקם בצד אחד של המסך והחלקים מסודרים בצד השני.

### שינוי מבוקש
הפאזל יהיה **במרכז המסך**, והחלקים יהיו מסודרים **מתחתיו** (פורטרייט) או **לידו** (לנדסקייפ) — אבל עדיין בצד אחד.

### מימוש
שינוי ב-`puzzle.ts`:
- `computeBeginnerDimensions()` — מרכוז אזור התמונה
- `compactInitial()` — מיקום החלקים ביחס למרכז

### אין הגדרה חדשה
זה שיפור להתנהגות הקיימת של `shufflePiecePlacement=false`.

## חלק 2: מסגרת + עוגן + חלקים בצדדים

### תיאור
- **מסגרת ויזואלית** סביב אזור הפאזל (רקע + border)
- **חלק עוגן** מקובע בפינה שמאלית-עליונה, לא ניתן להזזה
- **חלקים בצדדים** — מפוזרים משני צידי המסגרת:
  - לנדסקייפ: ימין ושמאל
  - פורטרייט: למעלה ולמטה

### הגדרה חדשה

```typescript
// ב-types.ts
interface TeacherSettings {
  // ...
  /** מסגרת פאזל עם חלק עוגן וחלקים בצדדים */
  useAnchoredFrame: boolean;
}
```

ברירת מחדל: `false`

### עיצוב המסגרת

```
לנדסקייפ:
┌─────────────────────────────────────┐
│                                     │
│ [חלקים]  ╔═══════════╗  [חלקים]    │
│ [חלקים]  ║  [עוגן]   ║  [חלקים]    │
│          ║           ║              │
│          ╚═══════════╝              │
│                                     │
└─────────────────────────────────────┘

פורטרייט:
┌───────────────┐
│   [חלקים]    │
│   [חלקים]    │
│ ╔═══════════╗ │
│ ║  [עוגן]   ║ │
│ ║           ║ │
│ ╚═══════════╝ │
│   [חלקים]    │
│   [חלקים]    │
└───────────────┘
```

### סגנון מסגרת
- רקע: `rgba(255,255,255,0.3)` או גרדיאנט עדין
- border: `3px dashed rgba(100,100,100,0.5)`
- border-radius קל

### התנהגות עוגן
1. חלק `(0,0)` — שמאל-עליון
2. ממוקם במקומו הסופי בתוך המסגרת
3. לא ניתן לגרירה
4. חלקים אחרים מתחברים אליו (הוא נשאר במקום)

### חלוקת חלקים לצדדים
- לפי המיקום המקורי בתמונה:
  - לנדסקייפ: חלקי חצי שמאל → צד שמאל, חלקי חצי ימין → צד ימין
  - פורטרייט: חלקי חצי עליון → למעלה, חלקי חצי תחתון → למטה
