# Speak Specs — 7 ניקודים נוספים

> ‏מפרט deterministic ל-executor: ‏לכל אות + ניקוד, ‏speak text ‏ו-filename. ‏אין החלטות לexecutor — ‏רק ביצוע.
>
> **קונטקסט:** ‏מתחיל אחרי שחיריק הסתיים (סבב 3). ‏הניקודים כאן: ‏סגול, ‏צירה, ‏חולם, ‏שורוק, ‏קובוץ, ‏חטף פתח, ‏חטף סגול. ‏שווא ועיצור — ‏לא בסקופ (Web Speech). ‏קמץ — ‏shared עם פתח (אין ייצור, ‏רק entries).
>
> **מקור הכללים:** ‏[`./lessons.md`](./lessons.md) — ‏לקחים מסבבים 1-3.

---

## ‏Default rule

‏אם אין override לאות+ניקוד מסוים — ‏ה-speak הוא:

```
speak = letter.displayChar + vowel.speakSuffix
```

‏(או ‏`letter.speakChar + vowel.speakSuffix` ‏עבור הרפות, ‏כמו ב-`makePair`.)

‏ה-suffix לכל ניקוד:

| ‏ניקוד | ‏speakSuffix | ‏הערה |
|--------|--------------|------|
| ‏סגול | ‏`ֶא` | ‏סיומת `א` — ‏לא בולע ח/ט |
| ‏צירה | ‏`ֵא` | ‏זהה — ‏לא בולע |
| ‏חולם | ‏`ֹא` | ‏זהה — ‏לא בולע |
| ‏שורוק | ‏`וּ` | ‏אין אות-עזר. ‏סביר שעובד. |
| ‏קובוץ | ‏`ֻ` | ‏בלי אות-עזר. ‏ייתכן קצר/חתוך — ‏לבדוק. |
| ‏חטף פתח | ‏`ֲא` | ‏קצר מאוד |
| ‏חטף סגול | ‏`ֱא` | ‏קצר מאוד |

## ‏Naming convention

‏בעקבות סבב 1 (`Ba.mp3` = ב+פתח) ‏וסבב 3 (`Bi.mp3` = ב+חיריק):

| ‏ניקוד | ‏suffix שם קובץ | ‏דוגמה (`b`) |
|--------|-----------------|--------------|
| ‏סגול | `e` | ‏Be.mp3 |
| ‏צירה | `ei` | ‏Bei.mp3 |
| ‏חולם | `o` | ‏Bo.mp3 |
| ‏שורוק | `u` | ‏Bu.mp3 |
| ‏קובוץ | `uu` | ‏Buu.mp3 |
| ‏חטף פתח | `ah` | ‏Bah.mp3 |
| ‏חטף סגול | `eh` | ‏Beh.mp3 |

## ‏שיתופי MP3 (אחיד לכל הניקודים)

‏לכל ניקוד, ‏זוגות האותיות הבאות חולקות קובץ MP3 ‏(אחת מייצרת, ‏שתיהן entries ב-`TTS_FILES`):

| ‏זוג | ‏צליל זהה |
|------|------------|
| ‏ס + שׂ | `s` |
| ‏ט + ת | `t` |
| ‏ק + כּ (דגושה) | `k` |
| ‏ו + ב רפה | `v` |
| ‏ח + כ רפה | `kh` |
| ‏א + ע | ‏אילם + תנועה |

‏**שמות קבצים — ‏בחירת המייצג** ‏(הראשון מייצר, ‏השני chairshare):
‏- ‏S.mp3 (ס) / שותף: ‏שׂ
‏- ‏T.mp3 (ט) / שותף: ‏ת (filename Tav<vowel>.mp3 — ‏Sonnet בחר ב-Tavi.mp3 בסבב 3; ‏אותו convention)
‏- ‏K.mp3 (כ דגושה) / שותף: ‏ק (filename Q<vowel>.mp3 בסבב 3)
‏- ‏V.mp3 (ו) / שותף: ‏ב רפה (filename Vr<vowel>.mp3 בסבב 3)
‏- ‏Ch.mp3 (ח) / שותף: ‏כ רפה (filename Chr<vowel>.mp3 בסבב 3)
‏- ‏A.mp3 (א) / שותף: ‏ע (filename Aa<vowel>.mp3 בסבב 3)

**‏עקרון:** ‏ייצור בודד פר זוג. ‏ב-`TTS_FILES` ‏שתי entries → ‏אותו filename. ‏לדוגמה:

```ts
'סֶא': 'Se.mp3',
'שֶׂא': 'Se.mp3',  // shared
```

## ‏Process פר ניקוד

‏לכל אחד מ-7 הניקודים:

1. ‏ייצור MP3 לפי הטבלה (default + overrides). ‏~20 קבצים unique.
2. ‏Gemini judge ‏פר קובץ.
3. ‏retry על קטועים (סביר שיהיו לפחות 1-2 פר ניקוד, ‏לפי חיריק).
4. ‏הוסף שורה ב-`<vowel>.html` ‏(דף לבדיקה).

‏אחרי שכל 7 הניקודים מוכנים:

5. ‏צור `all.html` ‏מאוחד.
6. ‏STATUS: NEEDS_DECISION ‏השני (לפי ‏brief פאזה 4 §4.3).

---

## ‏אם override לא עובד

‏אם Gemini ‏מסמן override כ-בעייתי:

‏- ‏**אל תנסה variants אוטומטית.** ‏סמן ב-judge-report ‏וקדם הלאה.
‏- ‏ב-NEEDS_DECISION השני, ‏המשתמש יחליט: ‏פשרה, ‏Web Speech fallback, ‏או iteration ידני.

‏(זה שונה מסבב 3 ‏שם variants הומצאו בזמן ריצה. ‏בסבב הזה — ‏אם הspec לא עבד, ‏מחכים להחלטה.)

## ‏Optional: shared MP3 ‏לחטפים

‏אם חטף פתח == פתח (צלילית) — ‏אפשר לדלג על ייצור חטף פתח לחלוטין, ‏ולמלא ‏entries ‏ב-`TTS_FILES` שמצביעים על MP3 של פתח. ‏אותו דבר לחטף סגול ↔ סגול.

‏אזה החלטה לcheck באמצע: ‏אחרי ייצור הסגול, ‏ייצור 2-3 חטף סגול ‏ובקש Gemini ‏להשוות. ‏אם זהה — ‏skip ייצור החטפים, ‏רק entries.

‏זה יחסוך ~40 קבצים. ‏החלטה לexecutor: ‏אם Gemini מאשר ב-2-3 דגימות, ‏skip. ‏אחרת — ‏ייצר.
