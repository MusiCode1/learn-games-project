## 4. ‏טכניקות לפי סדר עדיפות

‏כשיש בעיה עם אות מסוימת בניקוד מסוים:

1. **‏הברה עברית טבעית** — ‏default ‏(`'בִּי'`, ‏`'גְ'`, ‏וכו'). ‏עובד ל-~75% מהמקרים.
2. **‏שינוי סיומת**:
   ‏- ‏אם speak מסתיים ב-`ה` ‏והעיצור נבלע — ‏החלף ל-`א` (`'חָה'` → `'חָא'`).
   ‏- ‏אם speak מסתיים ב-`י` ‏והעיצור נבלע — ‏הסר את היוד (`'חִי'` → `'חִ'`).
   ‏- ‏אם speak מסתיים ב-`א` ‏וה-`א` נשמע מודגש מדי — ‏הסר אותה.
3. **‏Audio tag `[Israeli accent]`** ‏— ‏עוזר לאות צ בפתח. ‏בשאר הניקודים — ‏לא נבדק/לא עזר.
4. **‏תעתיק לטיני קצר** — ‏fallback אחרון:
   ‏- ‏`Fa`, ‏`Fi`, ‏`Fe`, ‏`Fo`, ‏`Fu`, ‏`Fə` (פ רפה — ‏תמיד)
   ‏- ‏`tsee`, ‏`tsa`, ‏`tso` (צ במקומות שעברית לא עובדת)
   ‏- ‏שווא נשמע כמו "ə" או "e" קצר באנגלית
5. **‏פשרה** ‏— ‏אם אף שיטה לא עובדת ‏וזה לא קריטי פדגוגית (כמו Ra), ‏אישור הצליל הקרוב ביותר עם תיעוד.
6. **‏Web Speech fallback** — ‏אם איכות מקובלת לא הושגה. ‏רעיון לאות בודדת, ‏לא לקבוצה שלמה.

## 5. ‏Process מומלץ לכל סבב ייצור

1. ‏**Pilot עם ניקוד אחד** ‏(לדוגמה חיריק) — ‏26 אותיות, ‏אבחון בעיות לפני batch גדול.
2. **‏אימות פר קובץ** — ‏Gemini judge ‏או האזנה ידנית. ‏אסור batch ללא verification.
3. **‏השוואה לטבלה למעלה** — ‏לכל אות בעייתית, ‏יישם את הטכניקה הידועה. ‏אל תמציא variants חדשים אם יש פתרון מתועד.
4. ‏**variants ל-flagged בלבד** — ‏אל תייצור 5 variants לכל אות. ‏רק לאלה שנכשלו ב-pilot.
5. **‏לא להעלות ל-R2 לפני אישור משתמש** — ‏cache הדפדפן (IndexedDB) ‏יחזיק גרסה רעה.
6. **‏שיתופי MP3** — ‏אותיות עם צליל זהה חולקות קובץ:
   ‏- ‏ס + שׂ
   ‏- ‏ט + ת
   ‏- ‏ק + כ (תלוי בניקוד, ‏לאמת עם Gemini)
   ‏- ‏ו + ב רפה
   ‏- ‏ח + כ רפה
   ‏- ‏א + ע (לרוב; ‏בעיצור — ‏שניהם Web Speech fallback)
7. **‏תיעוד ב-`tts-review/results.md`** ‏לכל סבב — ‏מה שעבד, ‏מה שנכשל, ‏ולמה.

## 7. ‏Cache caveat

‏ה-AAC proxy ‏משתמש ב-deterministic hash על ‏`provider|voiceId|modelId|text` — ‏אותו speak text תמיד מחזיר אותו MP3. ‏זה אומר:

‏- ‏אם variant מסוים נכשל וניסית שוב עם אותו speak — ‏תקבל את אותו קובץ.
‏- ‏אם רוצים variant חדש — ‏חייב לשנות **משהו** ב-speak (גם אם זה רק רווח נוסף).
‏- ‏צד שני — ‏אם speak זהה לקובץ קיים ב-R2 — ‏אין צורך לייצר שוב, ‏רק להוסיף entry ב-`TTS_FILES`.
