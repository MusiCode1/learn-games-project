# מיפוי אותיות דומות בעברית

מסמך זה ממפה את כל הצמדים של אותיות עבריות הדומות זו לזו, לצורך מימוש מנגנון "אותיות דומות" במשחק "איפה האות?".

יש שני סוגי דמיון:

1. **דמיון צורני (ויזואלי)** — אותיות שנראות דומות.
2. **דמיון צלילי (פונטי)** — אותיות שנשמעות דומות.

---

## 1. דמיון צורני (ויזואלי)

### 1.1 דמיון חזק — קל מאוד להתבלבל

| אות א' | אות ב' | סיבת הדמיון |
|--------|--------|-------------|
| ב (רפה) | כ (רפה) | צורה דומה מאוד, הבדל רק בפינה התחתונה |
| ו | ז | שתיהן אנכיות, ז' עם "ראש" קטן |
| ח | ה | דומות, ה' עם רגל שמאלית מנותקת |
| ח | ת | דומות בצורה הכללית |
| ע | צ | דומות, צ' עם "זנב" |

| ש (שמאלית) | שׂ (ימנית) | אותה צורה, הבדל רק במיקום הנקודה |

## 2. דמיון צלילי (פונטי)

### 2.1 דמיון צלילי חזק — צליל זהה או כמעט זהה

| אות א' | אות ב' | הצליל המשותף | הערה |
|--------|--------|--------------|------|
| ס | שׂ (שין שמאלית) | "ס" | צליל זהה לחלוטין בעברית מודרנית |
| כ (רפה) | ח | "ח" | זהה בעברית מודרנית |
| ב (רפה) | ו | "ו" | זהה בעברית מודרנית |
| ת (רפה) | ת (דגושה) | "ת" | זהה בעברית מודרנית |
| ק | כּ (דגושה) | "ק" | דומה מאוד בעברית מודרנית |
| ט | ת | "ט/ת" | זהה בעברית מודרנית |
| א | ע | אות אלמת | שתיהן בלי צליל בעברית מודרנית |

### 2.2 דמיון צלילי בינוני — אותיות גרוניות / שיניות

| אות א' | אות ב' | הערה |
|--------|--------|------|
| ה | א | בסוף מילה לפעמים מתבלבלים |
| ס | ז | שתיהן שיניות (חוששני / קולי) |
| צ | ט | דומות בהגייה אצל ילדים צעירים |

## 3. סיכום צמדים מומלצים למשחק

הצמדים החזקים ביותר לשימוש במנגנון "אותיות דומות" — אלה שיוצרים בלבול אמיתי אצל ילדים בגיל היעד:

### צמדים צליליים (Top 3 — אלה שהמשתמש ביקש)

1. **ש (שמאלית) ↔ ס** — שתיהן נשמעות "ס".
2. **כ (רפה) ↔ ח** — שתיהן נשמעות "ח".
3. **ב (רפה) ↔ ו** — שתיהן נשמעות "ו".

### צמדים צליליים נוספים מומלצים

4. **ט ↔ ת** — שתיהן נשמעות "ט".
5. **ק ↔ כּ (דגושה)** — שתיהן נשמעות "ק".
6. **א ↔ ע** — שתיהן אותיות אלמות.

### צמדים צורניים מומלצים

1. **ב (רפה) ↔ כ (רפה)** — צורה כמעט זהה.
2. **ד ↔ ר** — צורה דומה.
3. **ח ↔ ה** — צורה דומה.
4. **ו ↔ ז** — צורה דומה.
5. **ג ↔ נ** — צורה דומה.

## 4. השוואה למאגר הקיים (`LETTERS_PATAH`)

המאגר הנוכחי כולל 21 אותיות עם פתח. כל האותיות שכוללות דגש בצורתן הבסיסית (ב, כ, פ, ת) מוגדרות במאגר עם דגש בלבד.

### צמדים זמינים מלאים במאגר הנוכחי

| צמד | IDs | סוג דמיון |
|-----|-----|-----------|
| ט ↔ ת | `ta` ↔ `tav` | צלילי |
| ד ↔ ר | `da` ↔ `ra` | צורני |
| ח ↔ ה | `cha` ↔ `ha` | צורני |
| ו ↔ ז | `va` ↔ `za` | צורני |
| ג ↔ נ | `ga` ↔ `na` | צורני |
| י ↔ ו | `ya` ↔ `va` | צורני |

### צמדים שדורשים הוספה למאגר

כדי לממש את שלושת הצמדים הצליליים החזקים שהמשתמש ביקש, יש להוסיף למאגר:

1. **שׂ (שין שמאלית, פתח)** — לצורך הצמד `ש ↔ ס`.
2. **כ רפה (פתח)** — לצורך הצמד `כ ↔ ח`. צריך לחשוב איך לייצג רפה בעיצור עם פתח.
3. **ב רפה (פתח)** — לצורך הצמד `ב ↔ ו`. אותה בעיה כמו עם כ' רפה.
4. **ע (פתח)** — לצורך הצמד `א ↔ ע` (אם נרצה אותו).

### הערה על אותיות רפות עם פתח

בעברית תקנית, אות רפה בתחילת הברה היא חריגה — ב', כ', פ' בתחילת הברה אמורות להיות דגושות. **אבל** באמצע מילה יש מצבים שבהם אות רפה כן מקבלת פתח (למשל "אַבָּא" → "אַבַ-" באמצע מבנה דקדוקי, או צירופים כמו "שָׁבַת"). לכן ההצגה של "בַ" כרפה עם פתח היא לגיטימית מבחינה לשונית.

**ההחלטות שהתקבלו:**

| נושא | החלטה |
|------|-------|
| הצגה ויזואלית | אות רפה עם פתח (למשל בַ, כַ) — בלי דגש ובלי סימון רפה מיוחד |
| הקראה | לפי הצליל הרפה — `בַ` מוקראת "וַה", `כַ` מוקראת "חַה" |
| מבנה במאגר | מאגר נפרד לאותיות הרפות + מנגנון קבוצות שניתן לבחירה דרך ההגדרות |

## 6. מבנה קבוצות (Letter Groups)

הקבוצות הן יחידות **תוכן** שניתן להפעיל/לכבות דרך ההגדרות. בכל סבב המשחק שואב מהאיחוד של הקבוצות הפעילות.

יש שתי קבוצות בלבד מעבר למאגר הבסיסי:

| קבוצה | תיאור | אותיות |
|-------|-------|--------|
| `base` | המאגר הקיים — 21 אותיות עם פתח, ב/כ/פ דגושות | `a, ba, ga, da, ha, va, za, cha, ta, ya, ka, la, ma, na, sa, pa, tza, qa, ra, sha, tav` |
| `confusing` | אותיות מבלבלות (אותיות שלא במאגר הבסיסי ושיוצרות צמדים צליליים/צורניים חדשים) | `sa_sin` (שׂ), `aa` (ע) |
| `rafe` | אותיות רפות עם פתח | `va_rafe` (ב רפה), `cha_rafe` (כ רפה), `fa_rafe` (פ רפה) |

> **הערה:** קבוצת `rafe` היא בעצם תת-סוג של "אותיות מבלבלות" מבחינה צלילית, אבל מופרדת לקבוצה משלה כי היא מציגה תופעה לשונית מובחנת (אות בלי דגש), ויש משתמשים שירצו לתרגל אותה לבד.

### צמדי דמיון (similarity pairs)

צמדי הדמיון נשמרים **בנפרד** מהקבוצות. הם מגדירים אילו אותיות נחשבות "דומות" זו לזו לצורך מנגנון הבלבול במשחק. צמד פעיל רק אם שתי האותיות שלו זמינות בקבוצות הפעילות.

```ts
type SimilarityPair = {
  a: LetterId;
  b: LetterId;
  kind: 'visual' | 'phonetic';
  strength: 'strong' | 'medium';
};
```

**צמדים צליליים חזקים (המבוקשים):**

- `sha` ↔ `sa_sin` (ש שמאלית ↔ ס)
- `cha_rafe` ↔ `cha` (כ רפה ↔ ח)
- `va_rafe` ↔ `va` (ב רפה ↔ ו)

**צמדים צליליים נוספים (זמינים מיד במאגר הבסיסי):**

- `ta` ↔ `tav` (ט ↔ ת)

**צמדים צורניים (זמינים מיד במאגר הבסיסי):**

- `da` ↔ `ra` (ד ↔ ר)
- `cha` ↔ `ha` (ח ↔ ה)
- `va` ↔ `za` (ו ↔ ז)
- `ga` ↔ `na` (ג ↔ נ)
- `ya` ↔ `va` (י ↔ ו)

## 7. שילוב בהגדרות

ההגדרות יחשפו למשתמש שני צירים בלתי-תלויים:

1. **בחירת קבוצות אותיות** — אילו קבוצות תוכן פעילות (`base`, `confusing`, `rafe`).
2. **מנגנון "אותיות דומות"** — האם לכפות על הלוח לכלול לפחות צמד דמיון אחד, ובאיזה סוג (צלילי / צורני / שניהם).

המנגנון של "אותיות דומות" יעבוד רק על צמדים שכל שתי האותיות בהם זמינות בקבוצות הפעילות.
