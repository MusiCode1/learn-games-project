# תיעוד: מחולל הניקוד של "קריאה להמראה"

**מקור:** <https://kriale.co.il/vowels-generator/>
**תאריך בדיקה:** 2026-05-12
**מטרה:** תיעוד מנגנון הבחירה (ניקוד × אותיות × תצוגה) של האתר כבסיס לעיצוב מנגנון דומה למשחק "איפה האות?".

---

## 1. תמונה כללית

האתר הוא **מחולל תרגולי קריאה** המיועד למורים/הורים. המורה בוחר:

1. **אילו סימני ניקוד** רוצים לתרגל (בחירה רב-ערכית).
2. **אילו אותיות** רוצים לתרגל (בחירה רב-ערכית).
3. **סוג איורי תמיכה** (תומכי זיכרון / פרצופים).
4. **מצב תצוגה** (כרטיסים / טבלה).

לאחר לחיצה על **"בואו נתחיל"**, המחולל מציג את כל הצירופים האפשריים (אות × ניקוד) במצב התצוגה שנבחר, עם אופציה ל-TTS (`colbass.com`, voice `he-IL-AvriNeural`).

המבנה ב-DOM הוא טופס HTML רגיל (`<form id="generator_form" data-gen-type="vowels">`), כל בחירה היא `<input type="checkbox">` או `<input type="radio">` רגיל. הולידציה דרך `jquery.validate.min.js`, ההגשה ב-AJAX ל-`/wp-admin/admin-ajax.php`.

## 2. סימני ניקוד (`vowels[]`)

12 סוגי ניקוד + צ'קבוקס "הכל". כל ערך נשלח כ-checkbox עם `value=<code>` (האייקון הוא SVG עם שם קובץ זהה לערך).

| # | שם ניקוד | `value` | קובץ SVG | הערה |
|---|---|---|---|---|
| 0 | קמץ | `a+` | `a+.svg` | קמץ גדול = `ָ` |
| 1 | פתח | `a-` | `a-.svg` | `ַ` |
| 2 | שווא | `shva` | `shva.svg` | `ְ` (נח/נע — לא מבחין) |
| 3 | עיצור | `none` | `none.svg` | בלי ניקוד בכלל (אות עירומה) |
| 4 | סגול | `e+` | `e+.svg` | `ֶ` |
| 5 | צירה | `e-` | `e-.svg` | `ֵ` |
| 6 | חיריק | `i` | `i.svg` | `ִ` (עם/בלי יוד — לא מבחין) |
| 7 | קובוץ | `u-` | `u-.svg` | `ֻ` |
| 8 | שורוק | `u+` | `u+.svg` | `וּ` |
| 9 | חולם | `o` | `o.svg` | `ֹ` (חולם חסר/מלא — לא מבחין) |
| 10 | חטף פתח | `a-_` | `a-_.svg` | `ֲ` |
| 11 | חטף סגול | `e_` | `e_.svg` | `ֱ` |
| 12 | הכל | `all` | — | מטא-צ'קבוקס שמסמן את כל ה-11+1 שמעליו |

**הערות:**

- **חטף קמץ** (`ֳ`) **לא** מופיע. סביר שזה מכוון — אות נדירה ללומדי קריאה ראשונית.
- **דגש** (חזק/קל) אינו ניקוד כאן; הוא חלק מהאותיות (`בּ`, `כּ`, `פּ`, `תּ` הן כרטיסים נפרדים — ראו §3).
- **הקטגוריות "אותיות א-ת"** מקבילות לקטגוריית "תנועות" — האות `none` ("עיצור") מתפקדת כתנועה כדי שכל הציר יישאר אחיד (תמיד = אות × ניקוד).
- האייקונים הם SVG בלבד (לא טקסט) — `+/-` בשמות אינם מתמטיים אלא מבדילים בין "תנועה גדולה" ל"קטנה" באותה משפחה (a-קמץ vs a-פתח וכו').
- ולידציה: ה-fieldset הוא `required` עם הודעה `"חובה לסמן"`. בנוסף יש משתנה גלובלי `max_vowels_msg = "לא ניתן לבחור צירוף זה"` (ככל הנראה מונע בחירת ניקוד שלא קיים על אותיות סופיות — ראו §4).

**הערות חשובות:**

- האותיות הדגושות (`בּ`, `כּ`, `פּ`, `תּ`) הן **כרטיסים נפרדים** מהרפות (`ב`, `כ`, `פ`, `ת`). זה אומר שהמורה יכול לבחור "ב" בלי הדגושה אם הוא רוצה ללמד רק דגושה, ולהפך.
- **אות נפרדת** (ולא ניקוד) הן גם השיניים השמאלית והימנית של ש (`שׁ` ו-`שׂ`).
- האותיות הסופיות (`ך`, `ם`, `ן`, `ף`, `ץ`) מופיעות כאופציה אבל יש חוקיות:
  - לכל checkbox של אות יש `data-rule-check_sofiot="true"` עם הודעת שגיאה: **"סימנתם אותיות סופיות שלא יכולות להיות שווא/עיצור. שנו את הניקוד או את האותיות"**.
  - כלומר: סופיות **לא יכולות** להופיע עם `shva` או `none`. אם נבחרו שתיהן יחד הולידציה תיכשל.

## 4. עוד שתי קבוצות הגדרות

### 4.1 סוג איורים (`images_type`)

רדיו בלעדי (אחד מהשניים, או כלום):

- `regular` — **תומכי זיכרון** (איורים אסוציאטיביים, למשל א=אריה).
- `faces` — **פרצופים** (איורים של פנים שמדגימים את תנועת הפה לניקוד).

### 4.2 מצב תצוגה (`display`) — **חובה**

רדיו בלעדי:

- `table` — טבלה (גריד עם כל הצירופים בו-זמנית).
- `cards` — כרטיסים (אחד אחרי השני, ניווט קדימה/אחורה).

---

## 5. תצוגת התוצאות (אחרי לחיצה על "בואו נתחיל")

### 5.1 כרטיסים (`#cards`)

```
[הַשְּׁמַע]  1 / N           [<]  [>]
              <תוכן הכרטיס>
```

- כפתור **הַשְּׁמַע** מפעיל TTS (`<button class='sound_on'>`).
- מונה `1/N` שמתעדכן.
- חיצי ניווט `prev`/`next` (`disabled` בקצוות).
- ערבוב ידני דרך כפתור `data-action="refresh"`.

### 5.2 טבלה (`#table`)

- גריד CSS עם `--rows` ו-`--columns` כ-CSS custom properties.
- גדלים זמינים מהסרגל: **2×3**, **3×3**, **4×3**. (תפריט המובייל מציע רק 2×3 ו-3×3.)
- כל תא לחיץ ומפעיל TTS על התא הפעיל (`selectorBody=".card.active"` ב-`colbass-tts-wrap`).

### 5.3 סרגל הכלים הצמוד (sidebar)

קיים בשני צדדים — `right_sidebar` (תמיד) ו-`left_sidebar` (רק במסכים `lg`):

| כפתור | פעולה | נראות |
|---|---|---|
| מסך מלא | `data-action="fullscreen"` | תמיד |
| שיתוף | `data-action="share"` (mail/Facebook/WhatsApp/copy-link) | תמיד |
| ערבב | `data-action="refresh"` | תמיד (כפיל במובייל + דסקטופ) |
| החלף לטבלה | `data-action="change_display" data-display="cards"` | המעבר ההפוך מהתווית! |
| החלף לכרטיסים | `data-action="change_display" data-display="table"` | המעבר ההפוך מהתווית! |
| 2×3 | `data-action="change_table_size" data-size="2*3"` | רק במצב טבלה |
| 3×3 | `data-action="change_table_size" data-size="3*3"` | רק במצב טבלה |
| 4×3 | `data-action="change_table_size" data-size="4*3"` | רק דסקטופ |

> **נקודה מעניינת בקוד:** ב-HTML המקור התוויות "החלף לטבלה" / "החלף לכרטיסים" מצויות על כפתורים שערכם הוא `data-display` של ה-**מצב הנוכחי** (`cards` על הכפתור "טבלה"), ככל הנראה כי הם מוצגים לסירוגין (CSS מסתיר את הלא-רלוונטי).

## 7. הולידציה וחוקיות

מהטופס וה-JS המצורף (`generators.js`, `jquery.validate.min.js`):

1. `vowels[]` — **חובה** (`required`), הודעה: `"חובה לסמן"`.
2. `letters[]` — לא `required` בעצמו, אבל יש `check_sofiot`:
   - אם בחרו אחת מהסופיות `ך/ם/ן/ף/ץ` **וגם** הניקוד `shva` או `none` → שגיאה.
3. `display` — חובה (`required`).
4. `images_type` — לא חובה (אופציונלי).
5. הודעת `max_vowels_msg` ("לא ניתן לבחור צירוף זה") — כנראה למקרה שצירוף אות×ניקוד מסוים לא יוצר כרטיס תקין (אין אסט).
6. הודעת `gen_nores_popup` — "לא נמצאו תוצאות, בצעו בחירה מחדש."

## 8. סיכום המודל הנתוני

המודל המנטלי הוא **מכפלה קרטזית** מסוננת:

```
results = { (letter, vowel) | letter ∈ selected_letters, vowel ∈ selected_vowels }
          \ excluded_combinations  // למשל סופית+שווא, צירופים ללא אסט וכו'
```

עם metadata:

- `images_type` משפיע על האייקון/תמונה לצד הצירוף.
- `display` משפיע על הפריסה (כרטיסים/טבלה) ועל ה-pagination.
- "הכל" הוא **קיצור UI בלבד** — sugar שמסמן את כל ה-checkboxes שמעליו.

## 9. מיפוי לפרויקט שלנו

הקשר למשחק **"איפה האות?"** הקיים (`apps/find-letter-game`):

| Kriale | הפרויקט שלנו (קיים) | פער |
|---|---|---|
| 12 סוגי ניקוד | רק `pataḥ` (קמץ-פתח אחיד) | חסר 11 סוגי ניקוד |
| 32 אותיות + סופיות + שתי שיניים | 21 אותיות base + 6 confusing/rafe | חסרות סופיות + שיניים נפרדות |
| בחירה רב-ערכית מורה | `gridSize` בלבד | חסר UI בחירה |
| `images_type` | אין | אין צורך בשלב זה |
| `display: table/cards` | `gridSize: 2x3..4x4` | יש |
| הגייה רגילה/לשון הקודש | רק "רגילה" (ElevenLabs Sarah) | אופציונלי בעתיד |
| חוק סופית+שווא | אין (אין בכלל סופיות) | יעלה בעת ההרחבה |

### ההצעה למודל פנימי במשחק שלנו

יש כבר ב-`letters.ts` שדה `group: 'base' | 'confusing' | 'rafe'` ושדה `id`. כדי לאפשר מנגנון כמו של Kriale נצטרך:

1. **לרחיב את `LetterCard`** כך שייצג **אות + ניקוד** מפורשים:
   ```ts
   interface LetterCard {
     id: string;
     letter: string;       // 'ב', 'בּ', 'ך', 'שׁ' ...
     vowel: VowelCode;     // 'a+' | 'a-' | 'shva' | 'none' | ... (מאומץ מ-Kriale)
     display: string;      // 'בָּ' (חישוב או pre-baked)
     speak: string;        // 'בָּא'
     group?: ...;          // נשמר לתאימות
   }
   ```
2. **טבלת `vowels`** סטטית עם 12 הערכים (`a+`, `a-`, `shva`, `none`, `e+`, `e-`, `i`, `u-`, `u+`, `o`, `a-_`, `e_`). אם בשלב ראשון תומכים רק בחלק — לסמן `enabled: false`.
3. **טבלת `letters`** סטטית עם 32 התווים (כולל סופיות+שיניים+דגושות).
4. **`generateDeck(selectedLetters, selectedVowels)`** — מכפלה קרטזית עם פילטר:
   - סופית + (`shva` | `none`) → מסוננים.
   - חסר אסט (אם נחליט שלא לתמוך בכל הצירופים בהתחלה) → מסוננים.
5. **מסך הגדרות** עם שתי רשתות צ'קבוקסים + כפתור "הכל" לכל קטגוריה, בדומה למודל ה-HTML של Kriale (פשוט וטיפוסי).
6. **persistence** ב-`settings.svelte.ts` (כבר קיים) — שדה חדש `selectedVowels: VowelCode[]` ו-`selectedLetters: LetterId[]`.

### שאלות פתוחות לדיון

1. **TTS וצירופים חדשים** — היום קובץ ה-`speak` מבוסס על "אות+פתח+א" (`בָּא`). כשנוסיף ניקודים נוספים, נצטרך לייצר ולשמור MP3 חדש לכל צירוף (32×12 = עד 384 קבצים פוטנציאליים, פחות אחרי סינון). יש להחליט אם לבנות מראש או on-demand.
2. **תומכי זיכרון/פרצופים** — האם רלוונטי או מדלגים?
3. **לשון הקודש** — האם נדרש בשלב זה? (משמעות: עוד מערך MP3 שלם.)
4. **"הכל"** — האם להציע גם קיצורים תמטיים ("רק תנועות a", "רק אותיות שורש", "תנועות גדולות בלבד")?
